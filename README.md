# ORBIT — все мои приложения и одна подписка

ORBIT — это Telegram-бот с Mini App. Внутри — витрина приложений
(MERA, VELORA, DELTA и место под новые) и подписки в Telegram Stars:
на каждое приложение отдельно или на всё сразу.

## Как это устроено

```
           ┌──────────── ORBIT (этот проект, Railway) ────────────┐
Пользователь│  бот + Mini App:  витрина, оплата Stars, «Мои подписки» │
   ───────► │  база: кто, на что подписан и до какого числа          │
           └───────────────┬───────────────────────────────────────┘
                           │  GET /api/v1/access?user_id=…&app=…
          ┌────────────────┼────────────────┐
          ▼                ▼                ▼
        MERA            VELORA            DELTA
   (свой бот, Amvera) (свой бот, Railway) (свой бот, Railway)
```

- Приложения **не переезжают** и не переписываются — каждое остаётся своим ботом.
- Аккаунт один на всё — **Telegram ID**, без логинов и паролей.
- Подписка хранится **только в ORBIT**. Приложение спрашивает «есть доступ?» и получает «да/нет».
- Пакет «Всё включено» открывает и будущие приложения — их не надо докупать.
- Ты (ID из `ADMIN_IDS`) пользуешься всем бесплатно.

## Что где лежит

| Путь | Что это |
|------|---------|
| `hub/catalog.json` | **Каталог**: приложения, цены, ссылки, цвета. Здесь меняешь цены и добавляешь приложения |
| `hub/main.py` | Запуск сервера и бота |
| `hub/bot.py` | Команды бота и приём оплаты |
| `hub/api.py` | API для Mini App и для твоих приложений |
| `hub/access.py` | Правила: у кого к чему есть доступ |
| `hub/catalog.py`, `hub/payments.py`, `hub/initdata.py` | Проверка каталога, оплаты и входа из Telegram |
| `hub/db.py` | Таблицы в базе |
| `webapp/` | Mini App (HTML/CSS/JS, без сборки) |
| `integrations/hub_access.py` | Файл, который копируешь в MERA/VELORA/DELTA |
| `integrations/README.md` | Как подключить приложения — по шагам |
| `tests/` | Тесты |

## Запуск: шаг за шагом

### 1. Создай бота

1. В Telegram открой **@BotFather** → `/newbot`.
2. Имя: `ORBIT`, username: например `orbit_arche_bot` (должен заканчиваться на `bot`).
3. Скопируй токен — это `BOT_TOKEN`.
4. Узнай свой Telegram ID у **@userinfobot** — это `ADMIN_IDS`.

### 2. Проверь у себя на Mac

Открой папку проекта в VS Code, затем терминал (**Terminal → New Terminal**):

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Открой `.env` и впиши `BOT_TOKEN` и `ADMIN_IDS`. Затем прогони тесты:

```bash
python -m unittest discover -s tests -t . -v
```

В конце должно быть `OK`. Если что-то упало — пришли мне вывод целиком.

Запусти сервер:

```bash
uvicorn hub.main:create_app --factory --reload
```

Открой в браузере `http://127.0.0.1:8000/app/` — увидишь Mini App в демо-режиме.
Бот тоже уже отвечает на `/start` в Telegram. Остановить — `Ctrl + C`.

> Один токен — один запущенный бот. Когда ORBIT работает на Railway,
> локальный сервер не запускай, иначе Telegram выдаст ошибку `Conflict`.

> Из Telegram Mini App откроется только по https-адресу, поэтому
> полноценно (с оплатой) проверяем уже на Railway.

### 3. Залей на GitHub и Railway

1. Создай репозиторий и отправь код (команда — в сообщении с архивом).
2. На [railway.com](https://railway.com) → **New Project** → **Deploy from GitHub repo** → выбери `orbit`.
3. В проекте нажми **+ Create** → **Database** → **PostgreSQL**.
4. Открой сервис `orbit` → **Variables** и добавь:
   - `BOT_TOKEN` — токен бота;
   - `ADMIN_IDS` — твой ID;
   - `DATABASE_URL` со значением `${{Postgres.DATABASE_URL}}` — Railway подставит адрес базы;
   - `SUPPORT_CONTACT` — например `@arche7`;
   - `HUB_APP_KEYS` — пока можно пропустить (понадобится на шаге 5).
5. **Settings** → **Networking** → **Generate Domain**. Railway сам передаст этот адрес серверу.
6. Дождись зелёного статуса деплоя. В логах будет строка `Бот запущен, Mini App: https://…/app/`.

### 4. Проверь в Telegram

1. Открой своего бота → `/start` → кнопка **Открыть ORBIT**.
2. Ты админ, поэтому всё будет открыто. Чтобы проверить оплату как обычный
   пользователь, временно убери свой ID из `ADMIN_IDS` (или попроси друга).
3. Нажми на приложение → **Подписаться** → оплати Stars → через пару секунд планета на орбите загорится.

### 5. Подключи свои приложения

Пошагово — в `integrations/README.md`. Коротко: генерируешь ключи,
прописываешь их в ORBIT и в каждое приложение, копируешь `hub_access.py`
и добавляешь проверку в платные функции.

### 6. Замени ссылки-заглушки

В `hub/catalog.json` у VELORA и DELTA стоят ссылки `YOUR_VELORA_BOT` и
`YOUR_DELTA_BOT`. Замени на username своих ботов, например
`https://t.me/velora_coach_bot?startapp=orbit`. Пока заглушка не заменена,
кнопка «Открыть» у приложения не показывается.

`?startapp=orbit` открывает Mini App приложения сразу. Это работает, если у
бота настроено главное приложение: @BotFather → бот → **Bot Settings** →
**Configure Mini App**. Если не настроено — убери `?startapp=orbit`, тогда
просто откроется чат с ботом.

## Частые задачи

**Поменять цену.** `hub/catalog.json` → `price_stars` → коммит и пуш.
Уже оформленные подписки продлеваются по старой цене — так работает Telegram.

**Добавить новое приложение.** Сначала добавь его в `catalog.json` со
`"status": "soon"` — появится карточка «Скоро». Когда приложение готово,
поменяй на `"live"` и пропиши `link`. Подписчики «Всё включено» получат
доступ сразу.

**Вернуть Stars.** Напиши боту `/refund <user_id> <charge_id>` (работает
только для админов). `charge_id` есть в таблице `payments` в базе.

**Переименовать хаб.** Переменная `HUB_NAME` на Railway.
